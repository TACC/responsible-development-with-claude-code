Using Claude Code to Develop Software
=====================================

In this workshop, we will learn about Claude Code, Anthropic's agentic coding tool that lets developers
delegate programming tasks to Claude directly from the command line. It can read and understand a
codebase, edit files, run commands and tests, debug issues, and handle multi-step work like implementing
features or refactoring, all while working in your actual project environment.
We will use Claude Code to start a Python project, use plan mode, integrate with GitHub, teach Claude
your Python and GitHub requirements, go through the build/debug cycle, write unit tests, and use/install
new skills.
